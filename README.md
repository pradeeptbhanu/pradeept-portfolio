# Pradeept Bhanu Portfolio - GitHub Pages

This package is ready to host on GitHub Pages.

## Files
- `index.html` — main portfolio page

## Quick deploy steps
1. Create a new GitHub repository, for example: `pradeept-portfolio`
2. Upload `index.html` to the root of the repository
3. Commit and push to the `main` branch
4. In GitHub, open the repository
5. Go to **Settings** → **Pages**
6. Under **Build and deployment**, choose:
   - **Source**: Deploy from a branch
   - **Branch**: `main`
   - **Folder**: `/ (root)`
7. Save and wait a minute or two
8. Your portfolio will be published at:
   - `https://YOUR-USERNAME.github.io/pradeept-portfolio/`

## If you want the site at the root domain
If you want the site at:
- `https://YOUR-USERNAME.github.io/`

then the repository name must be:
- `YOUR-USERNAME.github.io`

and this same `index.html` should be placed in that repository root.

## Optional custom domain
If you later connect a custom domain:
1. Go to **Settings** → **Pages**
2. Add your custom domain
3. Update DNS with your domain provider
4. Wait for DNS verification and enable HTTPS
